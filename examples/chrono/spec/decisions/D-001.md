# Wrap and simultaneous event policy {#D-001}
<!-- ndf: kind=decision date=2026-11-02 affects=CNT-001,CTL-RST-001,CTL-SS-001 -->

**Context.** A two-digit count needs a rollover policy and simultaneous
events need a deterministic order.

**Decision.** Wrap at 99. Reset dominates all events and forces stopped.
Otherwise start/stop toggles before a tick is processed.

**Alternatives rejected.** Wrap at 59 would imply an unprovided minutes
display. Reset that preserves running makes clearing the stopwatch less
predictable. Counting based on the old running state was rejected in
favor of applying the control event first.

**Source.** This executable example's explicit design choices; this is not
a claim about the historical development of the proposal's appendix.
